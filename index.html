K-Nearest Neighbors (KNN) Classification

Classify a new data point using the labeled examples closest to it. Interactive demos on a cat vs. dog dataset.

Definition

To classify a new point, KNN finds the K training points closest to it and assigns the most common label among them (a majority vote).

It’s supervised (we have labeled examples) and non-parametric (we don’t force the answer to follow a straight line or any fixed shape; the data decides).

  1. 1
    Plot your labeled data: cats and dogs by height and weight.
  2. 2
    A new mystery pet shows up. Measure how close (similar) it is to every point.
  3. 3
    Pick the K closest points. These are its neighbors.
  4. 4
    Majority vote wins. That’s the prediction!

Why is training accuracy 100% at K = 1?

Each training point’s nearest neighbor is itself, so it always gets its own label right. That’s why we judge a model on new test data, never on the points it memorized.

Small K (like 1)

Jagged boundary, very flexible, but it fits random noise. That’s overfitting: great on training data, worse on new data.

Large K (like 30)

Smooth boundary, steadier, but too large misses real detail. That’s underfitting. Find the sweet spot by watching test accuracy.

Pros vs. cons

Pros

  • Easy to understand and explain
  • No assumptions about the shape of the data
  • Works with many classes (cat, dog, other…)
  • No “training” step: it just stores the data

Cons

  • Slow on huge datasets (measures distance to everything)
  • Uses a lot of memory
  • Features on different scales (inches vs. pounds) can mislead it
  • You have to choose K

Real-world applications

“Distance” really means “similarity”

Before the examples, one clarification: KNN only needs a way to measure how similar two things are. Close means similar, far means different. In the cat/dog plot, distance is literal (how far apart two points are on the graph). In a recommender, the “points” are people and each movie is an axis. Example with ratings from 1 to 5:

Movie AMovie BMovie C
Alex541
Sam552
Jordan125

Alex’s ratings are almost the same as Sam’s (distance √2 ≈ 1.4) but very different from Jordan’s (distance 6). So Sam is Alex’s nearest neighbor, and we would recommend movies Sam liked. Real systems use many more movies and other similarity measures, but the idea is the same: nearest = most similar.

Recommendations

Recommender systems suggest what your nearest neighbors liked: the users most similar to you in ratings, listening or purchases (see the example above). Neighbor-based similarity is a core idea behind recommendations on platforms like these:

Suggests shows and movies liked by viewers with similar watch histories.

Python example

from sklearn.neighbors import KNeighborsClassifier

# [height in inches, weight in lbs]
X = [[13, 20], [14, 25], [25, 40], [10, 15], [20, 35]]
y = ["Cat", "Cat", "Dog", "Cat", "Dog"]

model = KNeighborsClassifier(n_neighbors=3)   # K = 3
model.fit(X, y)                               # store the examples

new_pet = [[18, 30]]
print(model.predict(new_pet))
print(model.predict_proba(new_pet))
# output
['Cat']
[[0.66666667 0.33333333]]

The 3 closest pets to (18, 30) are one dog and two cats, so the vote is 2 cats : 1 dog (about 67% cat). In practice, features should be scaled to comparable ranges before computing distances.

Discussion questions

Why is an odd K often used with two classes?

It avoids ties. With K = 4 you could get 2 cats and 2 dogs. (Our demo breaks ties by trusting the closest neighbor.)

What goes wrong if weight is measured in grams and height in miles?

KNN is based on distance, so the axes must be on the same scale. If one feature has much larger numbers (grams run in the thousands, miles stay tiny), it dominates the distance calculation and the other feature barely matters. Before using KNN, rescale features to comparable ranges, for example by standardizing each one (subtract the mean, divide by the standard deviation) or rescaling to 0–1.

Can KNN predict a number instead of a category, like a price?

Yes. Instead of voting, take the average of the neighbors’ values. This is called KNN regression.

If K equals the total number of points, what does KNN always predict?

The most common class in the whole dataset, no matter where the new point is, because every training point votes every time.
